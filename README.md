# Zen Analytics Workbench — product page

A single self-contained HTML page. All images are embedded as data URIs and
there are no external requests, so it renders identically offline, as an email
attachment, or served from GitHub Pages.

Served at the repository root as `index.html`. `.nojekyll` is present so Pages
serves the file verbatim rather than running Jekyll over it.

To publish: Settings → Pages → Source: `main` / root.
